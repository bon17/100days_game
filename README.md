# 태어나 보니 식민지였다

중학교 3학년을 위한 역사 RPG 프로토타입입니다.
1929년 광주, 장학생이 꿈인 열다섯 살 윤재는 나라를 빼앗긴 뒤에 태어나 "원래 이런 세상"이라고 믿으며 삽니다.
장학생 수여식까지 100일 동안 차별과 식민지배를 겪으면서 마음속 믿음이 하나씩 깨져 갑니다.
(광주학생항일운동 배경, 인물은 모두 창작)

**1화 「공부만 잘하면 돼」**부터 **6화 「우리가 되찾을 거야」**까지, 1945년 광복 에필로그로 끝나는 전체 이야기를 플레이할 수 있어요.
- 1~4화: 믿음 네 개가 하나씩 깨져요. 5화 「태어나 보니 원래 이랬어」(10/30 나주역 ~ 11/3): 마지막 믿음이 깨지고, 강당·거리 중 한 곳을 골라요. 6화(11/4 ~ 11/12): 윤재가 스스로 독립운동에 나서요.
마지막에는 1929년부터 1945년까지 윤재와 친구들, 그리고 실제 역사 속 사람들의 불빛이 지도에 하나씩 켜지며 광복으로 이어지고, 11월 3일의 선택에 따라 엔딩 3종(히든 1종 포함) 중 하나를 보게 돼요.
타이틀의 **화 선택**으로 2화~6화부터 바로 시작할 수도 있어요.

## 플레이 방법
- `index.html`을 브라우저로 열면 바로 실행돼요. 설치할 것이 없어요.
- 태블릿과 폰 모두 **가로 화면**용이에요. 세로로 들면 돌려 달라는 안내가 나와요.
- 화면을 누르면 대사가 넘어가요. PC에서는 스페이스바나 엔터 키를 써도 돼요.
- 진행 상황은 그 기기에 자동 저장돼서, 타이틀에서 **이어하기**를 누르면 마지막 날부터 다시 시작해요.

## RPG 요소
- **자유 시간과 지도**: 하루에 2~3번 광주 지도에서 능력치를 키울 곳(학교·시장·냇가·책방·집)을 골라요. 이야기에 꼭 필요한 장면은 자유 시간 밖에서 자동으로 나와요.
- **능력치**: 학업·눈치·체력·용기. 능력치가 모자라면 잠기는 선택지가 있어요. 학업이 높으면 시험 시간이 늘어나요.
- **돈과 할 일**: 시장 짐 나르기 미니게임으로 돈을 벌어 월사금을 모아요.
- **1화 미니게임**: 시장 짐 나르기, 장학생 시험(수신 문제에서 윤재의 기억이 스쳐 가요).
- **2화 미니게임**: 소지품 검사(형사가 오기 전에 물건 숨기기), 골목 추격(위에서 본 골목 지도에서 형사를 피해 집까지), 심문(형사의 질문을 버티기).
- **3화 미니게임**: 벼 베기(타이밍), 되질 감시(속임수 되 찾기), 쌀 나누기(설날까지 버티기 달력).
- **4화 미니게임**: 주판 셈(은행 전표 더하기), 연설문 속 거짓 찾기(윤재가 1~4화에서 겪은 기억 카드로 연설문 문장 뒤집기).
- **5화 미니게임**: 증언 모으기(누구에게 물을지 고르기), 연설 따라 읽기 또는 구호 리듬(11월 3일 선택에 따라).
- **6화 미니게임**: 등사판 인쇄(롤러를 알맞은 속도로 밀어 실제 1929년 격문 찍기, 발자국이 뜨면 숨기), 담장 밖 신호(순사가 등을 돌릴 때 다가가고 종이 뜨면 누르기), 형무소 앞 대열 지키기(경찰이 밀면 꾹 눌러 버티고 틈이 나면 연타). 소리 없이 화면 표시만으로 할 수 있어요.
- **능력치 판정**: 파란 표시 선택지는 '성공 ○○%'가 보이고 주사위로 성공·실패가 갈려요. 실패해도 이야기만 달라져요.
- **목표와 쌀독**: 3화에서는 마감이 있는 목표(수리조합비)와 집에 남은 쌀, 4화에서는 최종 심사까지 장학생 게이지 목표가 화면 위에 보여요.
- **등급·업적·칭호**: 미니게임마다 S~C 등급, 업적 배지, 역사 노트 수집률, 능력치에 따른 칭호가 화 끝에 정리돼요.
- **소지품과 관계**: 참외·교본 같은 물건을 얻고 쓰며, 만식·정희·진수 형과의 관계(♥)가 쌓여요.
- **믿음과 마음**: 믿음 카드가 깨지면 새로운 '마음'을 얻어요.
- **가방**: 위쪽 가방 버튼에서 능력치·소지품·할 일·믿음·역사 노트를 볼 수 있어요.

## 역사를 몰라도 할 수 있게
- **프롤로그**: 1910년 국권 피탈부터 1929년 광주까지 그림과 함께 짧게 설명해요.
- **용어 말풍선**: 어려운 말이 처음 나오면 단어 위에 설명이 뜨고, 다시 나오면 밑줄을 눌러 볼 수 있어요.
- **역사 노트**: 꼭 알아야 할 배경이 나올 때 '알고 가기' 카드가 떠요.

## 폴더 구성
| 경로 | 내용 |
|---|---|
| `index.html` | 게임 화면 |
| `story/stage1.js` | **1화 대본**. 대사·선택지·시험·용어·역사 노트·아이템·지도 장소가 모두 여기 있어요. 맨 위에 쓰는 법이 있어요. |
| `story/stage2.js` | **2화 대본**. 2화 장소 이야기는 `## 장소2:이름`으로 써요. |
| `story/stage3.js` | **3화 대본**. 판정 선택지, 목표, 무작위 사건 쓰는 법이 맨 위에 있어요. |
| `story/stage4.js` | **4화 대본**. 주판 셈, 연설문 거짓 찾기(`@rebut`), 화별 지도 설명(`@spothint`) 쓰는 법이 맨 위에 있어요. |
| `story/stage5.js` | **5화 대본**. 사람 고르기(`@hub`), 등급 매기기(`@gradevar`), 리듬 게임(`@rhythm`) 쓰는 법이 맨 위에 있어요. |
| `story/stage6.js` | **6화 대본**. 등사판 인쇄(`@mimeo`), 담장 밖 신호(`@signal`), 대열 지키기(`@formation`), 마지막 카드(`@hopecard`)와 광복 에필로그. |
| `js/engine.js` | 대본을 읽어 실행하는 게임 엔진 |
| `css/game.css` | 화면 배치(태블릿·폰 반응형) |
| `assets/` | 게임에 쓰는 그림 (압축한 WebP) |
| `art_src/` | 그림 원본(PNG)과 그릴 때 쓴 프롬프트 |
| `tools/build_preview.py` | 링크로 공유할 한 장짜리 미리보기 파일을 만드는 도구 |
