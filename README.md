# D-100 · 1929 광주

중학교 3학년을 위한 역사 게임 프로토타입입니다.
1929년 광주, 장학생이 꿈인 열다섯 살 윤재가 100일 동안 차별과 식민지배를 겪으며
마음속 믿음이 하나씩 깨져 가는 이야기입니다. (광주학생항일운동 배경, 인물은 모두 창작)

지금은 **1화 「공부만 잘하면 돼」**(D-100 ~ D-78)까지 플레이할 수 있어요.

## 플레이 방법
- `index.html`을 브라우저로 열면 바로 실행돼요. 설치할 것이 없어요.
- 태블릿과 폰 모두 **가로 화면**용이에요. 세로로 들면 돌려 달라는 안내가 나와요.
- 화면을 누르면 대사가 넘어가요. PC에서는 스페이스바나 엔터 키를 써도 돼요.

## 폴더 구성
| 경로 | 내용 |
|---|---|
| `index.html` | 게임 화면 |
| `story/stage1.js` | **1화 대본**. 여기만 고치면 대사·선택지·시험 문제가 바뀌어요. 맨 위에 쓰는 법이 있어요. |
| `js/engine.js` | 대본을 읽어 실행하는 게임 엔진 |
| `css/game.css` | 화면 배치(태블릿·폰 반응형) |
| `assets/` | 게임에 쓰는 그림 (압축한 WebP) |
| `art_src/` | 그림 원본(PNG)과 그릴 때 쓴 프롬프트. 그림을 다시 만들 때 기준으로 써요. |
| `tools/build_preview.py` | 링크로 공유할 한 장짜리 미리보기 파일을 만드는 도구 |

## 그림
모든 그림은 OpenAI 이미지 모델로 생성했어요. 프롬프트는 `art_src/prompts/`에 있어요.
